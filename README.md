# Pizza Builder Pattern
A Java demo of the Builder design pattern using a pizza shop.

## Product
- `Pizza`: size, crust, sauce, and optional toppings (cheese, pepperoni, mushrooms).

## Representations
- `MargheritaPizzaBuilder`: thin crust, tomato sauce, cheese
- `PepperoniPizzaBuilder`: thick crust, tomato sauce, cheese + pepperoni

## How to Run
Run `Main.java` in your IDE
